# Distance-Calculator

## Description
My program calculates the distance between two points in a 2D coordinate using the standard distance formula and Python's math library, it also rounds the output to two decimal places for easier understanding.

## How to Run

1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- x1 : The x-coordinate of the first point
- y1 : The y-coordinate of the first point
- x2 : The x-coordinate of the second point
- y2 : The y-coordinate of the second point

## Sample Output

```
Enter the value of x1: 6
Enter the value of y1: 3
Enter the value of x2: 2
Enter the value pf y2: 5
The distance between the two points is: 4.47
```
